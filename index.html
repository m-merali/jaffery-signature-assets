Email signature assets

Logos, the KEBS ISO 21001 mark and social icons for the staff email signatures of Jaffery Academy Mombasa, JIPS and JNPS. Each asset is shown on a white panel and on a #1F1F1F panel, the background Outlook uses in dark mode.

In a signature, link the @2x file and set width and height to the 1x size shown first. Files in a v1/ folder never change, so signatures already sent keep working; a corrected file goes into a new version folder.
